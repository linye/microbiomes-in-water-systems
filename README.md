# Analysis of Microbiomes in Water Systems

This repository contains code and data for analyzing microbiomes in water systems. Due to file size constraints, only example input files are provided.

## 0. Software Requirements

- MMseqs2 (version 13.45111)
- Python 3.8
    - pandas == 2.0.3
    - numpy == 1.23.5
    - matplotlib == 3.7.5
    - seaborn == 0.13.2
    - networkx == 3.1
    - upsetplot == 0.9.0

## 1. Gene Catalogue Construction

### 1.1 `make_protein_clusters.py`

Process MMseqs-generated data.  
This script processes a large protein clustering table and writes cluster memberships by grouping sequences in a memory-efficient chunk-wise manner.

**Input**
- `protein_cluster.tsv`

**Output**
- `protein_clusters.txt`

---

### 1.2 `extract_rep_nucl_sequence.py`

This script extracts representative sequence IDs from an MMseqs-generated representative protein FASTA file and retrieves the corresponding nucleotide sequences from a reference FASTA file.

**Input**
- `protein_rep_seq.fasta`
- `nucl.fa`

**Output**
- `nucl_rep_extract.fa`

---

### 1.3 `process_cluster_info.py`

This script parses cluster memberships and metadata to generate environmental-level sample counts for each cluster.

**Input**
- `protein_clusters.txt`
- `env.txt`

**Output**
- `cluster_env_sample_number_matrix.txt`

---

### 1.4 `run_mmseqs_selfcompare.sh`

This script performs self-comparison for each FASTA file using MMseqs2 and exports pairwise alignments into TSV format.

**Input**
- `clusters30/*.fasta`

**Output**
- `results/*.tsv`

---

### 1.5 `make_rarefaction_curves.py`

This script computes rarefaction curves of protein clusters by progressively adding samples.  
It generates a global curve and environment-specific curves.

**Input**
- `protein_cluster.tsv`
- `env.txt`

**Output**
- `rarecurve.txt`
- `rarecurve-AS.txt`
- `rarecurve-DW.txt`
- `rarecurve-GW.txt`
- `rarecurve-MW.txt`
- `rarecurve-NW.txt`
- `rarecurve-WW.txt`

---

### 1.6 `summarize_env_combination.py`

This script summarizes environment co-occurrence patterns of clusters based on presence both exclusive and non-exclusive combination counts.

**Input**
- `cluster_env_sample_number_matrix.txt`

**Output**
- `env_combination_results.txt`

---

### 1.7 `jaccard_anlysis.py`

This script computes Jaccard similarity, directional gene flow, UpSet plots, and net directional flow networks among aquatic environments based on cluster occurrence data.

**Input**
- `env_combination_results.txt`

**Output**
- `jaccard_all_matrix.tsv`
- `jaccard_all_heatmap.png / .pdf`
- `jaccard_shared_matrix.tsv`
- `jaccard_shared_heatmap.png / .pdf`
- `directional_gene_flow_matrix.tsv`
- `directional_gene_flow_heatmap.png / .pdf`
- `directional_gene_flow_network.png / .pdf`
- `upset_all_clusters.tsv`
- `upset_all_clusters.png / .pdf`
- `upset_shared_clusters.tsv`
- `upset_shared_clusters.png / .pdf`
- `net_flow_values.tsv`
- `net_flow_barplot.png / .pdf`
- `global_flow_edges.tsv`
- `global_flow_nodes.tsv`
- `global_directional_gene_flow_network.png / .pdf`

## 2. IPG Identification

This script filters protein clusters that meet threshold criteria for each environment and generates six output files corresponding to 10%–60% thresholds.

**Input**

- `IPG_4group_30%.txt`

- `IPG_4group_50%.txt`

## 3. PIPG_analysis

### 3.1 (1)`cal_plasmid_arg_orf.py`

This script generates summary tables for each plasmid, including plasmid length, ORF count, and ARG count based on BLAST results, for both target and random plasmid datasets.

**Input**
- `plasmid_30_new.fasta`
- `plasmid_30_new_nucleotide_seq.fasta`
- `plasmid_30_new_resfinder_cov70.txt`
- `plasmid_random_1000.fasta`
- `plasmid_random_1000_nucleotide_seq.fasta`
- `plasmid_random_1000_resfinder_cov70.txt`

**Output**
- `plasmid_30_new_arg.txt`
- `plasmid_random_1000_arg.txt`

### 3.1 (2)`plot_plasmid_arg_orf.py`

This script analyzes the ARG summary tables generated by cal_plasmid_arg_orf.py. It performs statistical comparisons, calculates ARG/ORF ratios, generates a boxplot (log scale) of ARG/ORF ratios across plasmid types (small-plasmid, large-plasmid, shared-plasmid), and outputs statistical test results and summary reports to the console.

**Input**
- `plasmid_30_new_arg.txt`
- `plasmid_random_1000_arg.txt`

**Output**
- `arg_orf_ratio_boxplot_log.png/.pdf`

### 3.2 (1)`cal_plasmid_te_orf.py`

### 3.4 `Fisher.R`

This R script performs pairwise Fisher's exact tests to compare the enrichment of functional genes (VF, ARG, and TE) between PIPGs (target plasmids) and random plasmids (stratified by size: all, mega >100 kb, small ≤100 kb). It calculates odds ratios and p-values, applies Benjamini-Hochberg multiple testing correction, and outputs a summary TSV file.

**Input**
- `plasmid_30_new_vf.txt`
- `plasmid_random_1000_vf.txt`
- `plasmid_30_new_arg.txt`
- `plasmid_random_1000_arg.txt`
- `plasmid_30_new_te.txt`
- `plasmid_random_1000_te.txt`

**Output**
- `Fisher_exact_PIPG_random_all_and_size.tsv`

### 3.5 `abundance.py`

This script calculates per-plasmid abundance metrics (raw counts, RPKM, TPM, and coverage percentage) for each sample based on coverage count files, and generates summary statistics across all samples.

**Input**
- `plasmid_lengths.txt`
- `coverage_counts/*_plasmid_coverage_counts.txt`

**Output**
- `plasmid_abundance_counts.csv`
- `plasmid_abundance_RPKM.csv`
- `plasmid_abundance_TPM.csv`
- `plasmid_abundance_coverage_pct.csv`
- `sample_summary_stats.csv`

### 3.6 `prevalence.py`

This script analyzes plasmid prevalence (presence/absence across samples) based on coverage data. It filters plasmids with coverage >60% per sample, calculates the prevalence of each plasmid within each group (stratified by size: large ≥100 kb vs small <100 kb), and generates stacked histograms and summary plots.

**Input**
- `coverage.txt`
- `length.txt`

**Output**
- `result/plasmid_prevalence_histograms.png/.pdf`
- `result/plasmid_prevalence_summary.png/.pdf`
- `result/filtered_plasmid_samples.csv`
- `result/plasmid_prevalence_data.csv`
- `result/plasmid_length_info.csv`

### 3.7 `iRep_box.R`

This R script analyzes iRep values across sample groups (DW, AS, WW, NW, GW) and taxonomic levels (Order, Family, Genus). It generates per-group histogram+boxplot combinations, taxonomic boxplots with pairwise significance testing (Wilcoxon), overall group comparisons via Kruskal-Wallis with post-hoc tests, and summary statistics.

**Input**
- `iRep_box.txt`

**Output**
- `iRep_by_group.png/.pdf`
- `iRep_by_Order.png/.pdf`
- `iRep_by_Family.png/.pdf`
- `iRep_by_Genus.png/.pdf`
- `group_comparison.png/.pdf`
- `iRep_summary_statistics.csv`
